📋 新旅團部署指南 - 有主系統 / 無主系統 兩條路 (10分鐘)

🌟 先了解一下：主系統平台是什麼？

你而家用緊嘅 樂行童軍進度追蹤 係一個 Tier 3 元件，可以獨立用，但其實屬於更龐大的 scoutsystem-2.0 主系統平台：

  • 📊 Dashboard 儀表板：全旅團人數、活動、財政一目了然
  • 👥 成員管理、✅集會考勤 QR Code、💰財務、📅活動報名
  • 🧩 插件市場：本系統是其中一個插件，可一鍵加入卡片
  • 🔐 單一登入：點卡片自動帶入身份，唔使再輸 YMIS/密碼

重點：有主系統 ≠ 一定要接上本系統，可自由選擇獨立用或接上，兩條路並存不衝突。藉此告訴用家有更大平台可用。

📖 使用教學

1

選擇旅團

首頁點擊旅團卡片（例如 0082 第82旅）

2

登入

成員：YMIS 10位數字 + 密碼；領袖：Email + 密碼。首次登入預設密碼：1234（登入後可更改）。

3

成員操作：申請完成

成員不可直接勾選，點擊「📝 申請完成」→選擇日期→填寫證據→提交。領袖會在「待批」頁看到。

4

領袖操作：勾選+日期

領袖可直接勾選，系統自動填今日日期，亦可手動改日期。所有勾選先存瀏覽器，底部顯示未保存數量，按「確認寫入」才批量寫入雲端，寫入時有進度提示。

5

其他功能

全團總覽：按段章篩選，避免卡死；按項目統計：百分比+人數；其他獎章已併入我的進度；表格列印：樂行童軍官方格式 (PT/21 / PT/22 / PT/69) 自動填入後列印。

📥 批量開戶 - 領袖專用

方法一（最推薦）：YMIS 報表匯入
在 YMIS 匯出「自訂報表」PDF（欄位次序：童軍成員編號 → 中文姓名 → 電郵地址），直接上載，系統會自動讀出成員資料，預覽確認後一次過開戶。

📘 如何在 YMIS 匯出指定格式報告？（點擊展開）
步驟一：搜尋與篩選旅團成員
  1. 登入 青少年成員資訊系統 (YMIS)。
  2. 點選頂部選單「功能」→「搜尋成員紀錄」。
  3. 展開「成員紀錄」區塊：選擇所屬「地域」及「童軍區」，在「童軍旅」輸入你的旅團代號。
  4. 按「搜尋」，在成員列表勾選要匯出的成員，或勾選最上方的「全選」。
步驟二：編製報告 → 自訂報表
  1. 按搜尋結果上方的「編製報告」。
  2. 報告種類：切換為「自訂報表」；上方「排列」與「第二排列」可略過不變。
步驟三：欄位次序（最關鍵！）
必須嚴格依序把左側欄位加入右側「已選擇之項目」：
  1. 童軍成員編號（＝系統的 YMIS）
  2. 中文姓名（＝姓名）
  3. 電郵地址（＝聯絡電郵）
💡 欄位先後次序完全取決於加入右側的先後次序；右側每欄的寬度百分比可維持預設（例如 100%）。
步驟四：產出與下載
  1. 確認右側次序為：童軍成員編號 → 中文姓名 → 電郵地址。
  2. 按右下角「確定」，系統自動產生並下載 PDF。
🔐 PDF 有密碼？
YMIS 匯出的 PDF 多數帶密碼保護。本 APP 支援直接輸入密碼解鎖讀取；若仍讀不到，可用 Chrome／Edge 開啟 PDF（輸入密碼）→ 列印 → 目的地選「另存為 PDF」，儲存出來的新檔案就沒有密碼。詳見 YMIS 匯出教學。
讀不到 PDF？可把報表文字複製貼上（每行：編號 姓名 電郵）：

🔒 PDF 解密在瀏覽器內以 pdf.js 完成，檔案與密碼都不會上傳伺服器。

方法二：上傳 CSV
先按「⬇️ 下載成員範本」取得範本，填寫後上傳。全部成員都會開立可登入帳號（密碼留空＝預設 1234）。

方法三（進階／備用，日常不建議）：Google Sheets 直接寫入
把 CSV 匯入 Google Sheets → 填寫 → 用附帶的 Apps Script（Code.gs）轉 JSON 並直接寫入旅團主資料表。詳見 批量開戶說明。

📝 CSV 欄位：ymis,name,email,role,can_tick,password,note

  • ymis 成員必填10位數字；領袖可留空（用電郵登入，系統自動編配）
  • name (必填) 中文姓名
  • email 電郵（領袖必填，用作登入帳號）
  • role 角色：member / exec_committee / branch_leader / group_leader / admin
  • can_tick true / false 是否可勾選
  • password 留空＝預設密碼 1234；有填＝用自訂密碼
  • note 備註（聯絡方式/特殊需要等）
