# 👨‍💼 領袖使用教學 (Branch Leader / Group Leader / Admin)

> 你擁有全部權限，負責審批、授權、批量操作

## 核心功能

### 1. 我的進度 - 選成員看所有紀錄
- 頂部「檢視成員」下拉選任何人，查看其完整進度（包括其他獎章）
- 直接勾選 + 輸入日期（剔即填今日，可手改日期）
- 級聯自動完成：勾上層自動勾所有下層
- 離線暫存 → 底部 SaveBar 顯示數量 → 按確認才批量寫入雲端，有進度提示

### 2. 全團總覽 - 一眼睇 + 批量剔
- **卡片總覽**：每人完成度% + 四個獎章百分比，一眼睇邊個完成會員章（顯示會員章✓標籤）
- **表格矩陣**：按段章篩選，最多30欄防卡死，點✓可單獨切換
- **🚀考驗營批量完成**：例如剛去完考驗營
  - 選日期
  - 左選有去的成員（支援搜尋過濾，全選/取消全選）
  - 右選本次考驗的項目（支援全選）
  - 一鍵標記 → 暫存 → 確認寫入，唔使逐個跳轉
- **按成員/按項目統計**：子切換按鈕，一個分頁內完成（手機省闊度）

### 3. 待批 - 成員申請
- 成員「申請完成」後在此顯示，含日期、證據
- 可單個批准/拒絕，或批量選中批准
- 批准後自動加入待寫入清單

### 4. 📅 活動履歷 - 服務／活動／訓練班紀錄（v8.1）
- 記錄成員參加的各項活動：**🤝 服務紀錄**（名稱、崗位、時數，自動統計總時數）、**🏕️ 活動紀錄**（露營、比賽、參觀等）、**🎓 訓練班紀錄**（班名、身份、時數、證書編號）
- 「檢視成員」可切換任何成員；成員登入則唯讀看自己
- **➕ 新增紀錄**：選類型 → 成員 → 日期 → 名稱 →（崗位／時數／證書編號按類型顯示）→ 儲存
- **📥 批量補登**：新增時勾「批量：同一活動套用到多個成員」，例如全團露營一次過幫 20 人建立（單次最多 200 筆）
- ✏️ 編輯／🗑️ 刪除：紀錄右側按鈕（刪除會先確認，且寫入操作紀錄可追查）
- 權限：與進度寫入相同——需角色含勾選權且「授權勾選」開啟的領袖；成員唯讀
- ⚠️ 如顯示「後端尚未升級 v8.1」： Apps Script 貼上最新 Code.gs → 執行 initializeSheets() 補建「活動履歷」工作表 → 部署 → 管理部署 → 編輯 → 版本選「新版本」→ 部署

### 5. 表格列印 - 官方格式
- 自動填入姓名、YMIS、旅團、段章完成日期、其他獎章
- PT/21 樂行童軍獎章、PT/22 貝登堡獎章官方格式，含個人摘要、完成項目、提名/推薦/批核簽署欄
- 可編輯後列印，雙面列印符合總會要求

### 5. 用戶管理 - 角色及細緻權限
- 將成員改為管委：選單改角色 + 授權勾選
- **📥 批量開戶**：一次過為全團開戶，不用逐個填表
  - **方法一（最推薦）**：在 YMIS 匯出「自訂報表」PDF（欄位次序：童軍成員編號 → 中文姓名 → 電郵地址），APP 內直接上載（可輸入 PDF 密碼，瀏覽器內解密），預覽確認後一鍵開戶。教學見 [YMIS_EXPORT.md](YMIS_EXPORT.md)
  - **方法二**：下載 CSV 範本 → 填寫 → 上傳（有密碼＝開登入帳號；無密碼＝只加入名單）
  - **方法三（備用）**：Google Sheets + Apps Script 直接寫入主資料表，見 [BULK_ONBOARD.md](BULK_ONBOARD.md)
  - 個人開戶：成員在登入頁「🆕 申請成員帳戶」→ 領袖在「✅ 審批中心」批准
- **⚙️權限按鈕**：
  - 領袖默認全部(*)
  - 成員默認無
  - 管委默認 L1會員章 + L3活動段章 + OTHER部分
  - 可按個別成員勾選可考核什麼：會員章、活動段章（細項不用）、其他獎章逐個勾
  - 高層級可設定低層級可勾選範圍，除非團長/管理員更改
- 授權/收回勾選權限

### 6. 系統設定 - 私隱開關
- **允許成員互相查看進度**：預設關（只看自己，重私隱），團長可開啟（互相鼓勵，管委可按進度策劃活動）
- 在用戶管理頁 → 系統設定 → 開關
- 成員是否可看其他人進度由此控制

### 7. 審批申請
- 審批新帳號申請（YMIS/Email）

### 8. 資料庫
- 訓練綱要對照、訓練計劃、保護兒童 Safe from Harm 連結、佩戴指引、表格下載
